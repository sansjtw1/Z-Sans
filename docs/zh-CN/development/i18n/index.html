Internationalization

上一页 下一页

Z-Sans 内置中英文（zh_CN / en）支持，基于标准 gettext（.po / .mo）实现。

目录结构¶

i18n/
├── en/LC_MESSAGES/
│   ├── messages.po    # 源字符串
│   └── messages.mo    # 编译后的二进制
└── zh_CN/LC_MESSAGES/
    ├── messages.po
    └── messages.mo

配置¶

language:
  default_language: en      # zh_CN 或 en
  supported_languages:
    - zh_CN
    - en
  locale_dir: i18n          # 语言文件目录

工作原理¶

  1. main() 先用 pre-parser 解析 -c/--config 得到配置文件路径
  2. setup_i18n(config) 加载语言：
  3. 从配置 language 节读取默认语言与支持列表
  4. 默认语言不在支持列表 → 告警并回退 zh_CN
  5. locale_dir 相对项目根解析；目录不存在 → 报错并回退 i18n
  6. gettext.translation('messages', ...) 加载语言包并 install()
  7. 失败时回退英文
  8. argparse._ = _：把翻译函数注入 argparse，使 -h/--help 等内置文案也走同一翻译
  9. 日志与提示全部经 _() 包装

开发者使用¶

在代码中使用：

from core.i18n import _

logger.info(_("Breeding engine started"))
engine.start(_("Scanning..."))

新增字符串后更新 .po 文件并重新编译为 .mo（工具如 Babel / msgfmt）。

当前语言查询¶

from core.i18n import get_current_language
lang = get_current_language()   # 'zh_CN' | 'en'

HTML 报告与 Web 控制台的界面语言也跟随此配置：

  • HTML 报告：zh 前缀 → lang="zh-CN"
  • Web 控制台：GET /api/i18n 返回 {lang, dict}（80+ 个前端文案 key），前端通过 t(key) 查询
