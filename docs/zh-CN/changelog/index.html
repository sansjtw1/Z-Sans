v0.1.0（2026-09-13）¶

新增¶

  • TLS 证书富化：完整探测证书（subject / issuer / 有效期 / SAN / SHA-256），并用 SAN 发现子域；新增 cert-expired、cert-expiring、cert-self-signed、cert-hostname-mismatch 发现。同时修复了一个潜在缺陷：CERT_NONE 下 getpeercert() 返回空，导致 SAN 从未被提取
  • 泛解析检测：随机标签探测，剔除 DNS 爆破假阳性
  • 历史 URL：可选的 Wayback（CDX）与 Common Crawl 采集，产出为 URL 资产
  • 子域接管检测（仅检测）：CNAME 链匹配已知云服务，可选 HTTP 确认；结果为 findings
  • 全局限速（http.rate_limit）与每工具并发上限（concurrency.tools，此前为死配置）
  • 跨运行磁盘缓存（cache，sqlite）缓存 DNS / HTTP / 证书结果；--watch 旁路 HTTP 缓存
  • 完整 IPv6 支持（校验、作用域判断、端口扫描、URL 与 uid 方括号）
  • 新增导出：SARIF 2.1.0（output.formats.sarif，默认开启）与 Neo4j/BloodHound CSV（output.formats.neo4j）；报告新增 Findings 页签；GET /api/projects/<id>/sarif
  • Findings 模型（properties.findings），随 JSON / CSV / GraphML / 报告 / SARIF 呈现

修复¶

  • 重复发现丢边：discovered 边与 on_asset_discovered 事件此前依赖 add_asset() 返回 True。已被扫描/淘汰/扫描中的资产会返回 False，导致新父节点重复发现它时边与事件被静默丢弃。现在边与事件无条件记录，仅"是否重新入队"由返回值决定
  • 并发重复扫描：queue.get_next() 在资产状态变为 scanning 之前就把它移出 _queued，窗口内的重复发现会再次入队，同一资产被两个 worker 并发扫描。现在 uid 保留为"处理中"，直到新增的 queue.done(asset)（任务完成时调用）才移除
  • 资源上限超发（TOCTOU）：按类型配额（max_domains / max_urls 等）的"先检查、后自增"两步之间没有共享锁，并发 worker 最多超发（worker 数）个。新增原子 AssetGraph.try_add_asset(asset, max_count)，在图的锁内完成检查与占位

变更¶

  • HTTP 会话线程安全：原先单个全局 requests.Session（非线程安全）改为通过 get_http_session() 每线程一个实例，配置变更（代理 / UA / SSL）经代次号传播。旧名 http_session 作为兼容别名保留并转发到当前线程的 Session，旧插件无需改动
  • 版本号单一来源：新增 core/version.py，main.py、webapp.py 与 HTML 报告页脚统一读取 0.1.0（此前多处硬编码 0.0.5 / 0.0.6）

工具链修复¶

  • 临时文件泄漏：内置 DNS 解析器与端口扫描器创建的 NamedTemporaryFile 从未使用也从不删除；naabu / JSfinder 的清理不在 finally 中，异常路径会残留文件
  • i18n 补全：补齐遗漏的翻译条目，并新增 tools/build_i18n.py，用 polib 把 .po 编译为 .mo（无需 msgfmt）
  • 新增 pytest 测试套件覆盖上述修复

v0.0.9（2026-08-25）¶

安全¶

  • Web 控制台认证：设置环境变量 ZSANS_WEB_PASSWORD 后，除登录和登出接口外均需口令授权。浏览器走独立登录页（HttpOnly 会话 Cookie）；第三方程序可通过 Authorization: Bearer <口令> 或 X-API-Key 请求头直接接入。含登录限流
  • 命令注入修复：外部工具（subfinder / EHole）一律改为参数列表调用，删除了 Windows 下 shell=True 字符串拼接路径
  • Web 种子校验：Web 提交的种子在触达工具命令行前做严格格式校验（域名/URL/IP 白名单）
  • SSE 日志流不再发送 Access-Control-Allow-Origin: *；请求体上限 2 MB

修复¶

  • 种子作用域：以公共后缀表（PSL）计算注册域，取代旧的"取末两段"逻辑（内置 PSL 数据，离线可用）。example.co.uk 不再被错误上拆到公共后缀 co.uk，同时 www.example.com 仍能覆盖 example.com。新增配置项 asset_scope.seed_scope: registrable | exact
  • 种子域名统一归一化为小写（此前 -d EXAMPLE.COM 会导致相关性匹配全错）
  • 域名相关性判断改用 hostname（去端口），带端口的 URL（如 http://target.com:8443/）不再被误判为无关而导致站内链接全部丢失
  • 含凭据的代理 URL 写入日志前已脱敏
  • 补齐前端缺失的 i18n key（enter）；策略下拉选项本地化

变更¶

  • 控制台日志大幅降噪：逐资产/逐链接日志降级为 DEBUG（仍完整写入 zsans.log），改为每处理 25 个资产输出一次进度心跳 + 扫描结束时输出汇总
  • 补完剩余硬编码字符串的国际化（API 错误消息、CLI 插件列表标签、前端弹窗文案）
