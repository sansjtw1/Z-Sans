Output & Reports

上一页 下一页

每次扫描完成，Z-Sans 会在输出目录下生成一个带时间戳的项目目录，内含完整的资产图与交互式报告。

目录结构¶

output/                            # 根目录（配置 output.dir / -o）
└── 20260812_231800/               # 时间戳子目录 YYYYMMDD_HHMMSS
    ├── zsans_20260812_231800.json          # 完整资产图
    ├── zsans_20260812_231800_assets.csv    # 资产表
    ├── zsans_20260812_231800_relations.csv # 关系表
    ├── zsans_20260812_231800.graphml       # GraphML 拓扑
    └── zsans_20260812_231800_report.html   # 交互式 HTML 报告
  • 前缀：默认 zsans，由配置 output.output_prefix 控制
  • 时间戳：%Y%m%d_%H%M%S（本地时间）
  • 目录创建时机：引擎 start() 时预创建并缓存；插件产物写入同一目录，可通过 engine.output_handler.run_dir 访问

文件生成受 output.formats 各开关控制（html 映射为内部报告类型 report）。

JSON 资产图¶

{prefix}_{timestamp}.json — 全量资产图的机器可读格式，是 Web 控制台与项目对比的数据源。

{
  "schema_version": 2,
  "zs_version": "0.0.7",
  "stats": { "nodes": 120, "edges": 310 },
  "metrics": {
    "assets_processed": 120,
    "new_assets_found": 115,
    "depth_reached": 4,
    "errors": 0
  },
  "seeds": { "domains": ["example.com"], "ips": [], "ip_ranges": [] },
  "config_hash": "<sha256 of config>",
  "generated_at": "2026-08-12T23:18:00",
  "nodes": [
    {
      "uid": "domain:example.com",
      "type": "domain",
      "value": "example.com",
      "source": "manual",
      "depth": 0,
      "state": "scanned",
      "properties": { "domain": "example.com" }
    }
  ],
  "edges": [
    { "source": "domain:example.com", "target": "ip:93.184.216.34", "relation": "resolved" }
  ]
}

CSV 资产表¶

{prefix}_{timestamp}_assets.csv — 带 BOM（UTF-8-sig），Excel 直接打开无乱码。

列 说明
ID 资产唯一标识 type:value
Type domain / ip / url / port / js / cert
Value 资产值
Depth 发现深度
Discovery Time 发现时间 %Y-%m-%d %H:%M:%S
State new / scanning / scanned / eliminated / failed / excluded
Title/Note url 资产取标题（受 max_length 截断）；port 资产取服务名
Fingerprints url 资产逗号拼接的指纹列表
CMS 指纹识别出的 CMS
Server 服务端信息

CSV 关系表¶

{prefix}_{timestamp}_relations.csv — 3 列：

列 说明
Source Asset ID 源资产值（剥离 UID 前缀）
Target Asset ID 目标资产值
Relation Type discovered / resolved / hosted

GraphML 拓扑¶

{prefix}_{timestamp}.graphml — 标准 GraphML 1.0 有向图，可用 Gephi、Cytoscape 等可视化。

  • 节点 id：资产 UID（type:value）
  • 节点属性 key：type、value、depth、discovery_time、state，以及 url 资产特有的 title、fingerprints、cms、server
  • 边属性 key：relation

HTML 报告（推荐查看）¶

{prefix}_{timestamp}_report.html — 自包含交互式报告（内联 JS/CSS，无需外网），打开即用。

概览 Tab¶

  • 统计卡片：总资产、总关系、已处理、新发现、最大深度、耗时、种子数
  • Seed 资产清单（域名 + IP）
  • Top Hosts：按度数降序前 15
  • 资产类型分布：横向条形图 + 环形图

拓扑 Tab¶

  • 原生 Canvas 力导向拓扑图（无第三方图库）
  • 节点 > 300 时按度数截断到 300
  • 节点按类型着色，半径随度数增大，缩放 > 1.6 显示标签
  • 拖拽平移、滚轮 / 双指缩放（0.05~8x）、自适应 fit

活跃资产 Tab¶

资产表格（Type/Value/Depth/Discovery Time/State/Title-Note/Fingerprints/CMS/Server）+ 实时筛选。

排除资产 Tab¶

被排除资产的表格 + 原因；需配置 output.keep_eliminated_assets: true（默认开）才有数据。

指标 Tab¶

  • engine.metrics 全量 key-value
  • 端口分布（服务 / 数量）
  • 排除原因统计（原因 / 数量）

筛选与搜索¶

  • 搜索框：整行文本不区分大小写包含匹配
  • 三个下拉筛选器：Type、State、Depth
  • 计数实时更新：Showing N assets (filtered)

报告语言跟随 i18n 配置（zh 前缀 → lang="zh-CN"）。

检查点文件¶

<output_dir>/checkpoint.json（默认位置）用于断点续扫：

  • 触发保存：每处理 checkpoint.interval（默认 50）个资产、以及 stop() 时
  • 原子写入：先写 .tmp → flush + fsync → os.replace，防止中断损坏
  • 内容：种子、metrics、所有节点、边三元组、待处理队列
