Configuration Reference

上一页 下一页

Z-Sans 通过 YAML 配置文件控制扫描行为。默认路径为 breeding-config.yaml。

配置加载机制¶

生成默认配置¶

python main.py --init

若目标文件不存在，--init 会整文件复制 templates/breeding-config.yaml（带完整中文注释）；模板不可用时才回退为内置默认值转储。

配置合并规则¶

配置文件通过递归深合并与内置默认值合并：

  • 字典递归合并（只写部分字段，其余保留默认）
  • 列表与标量直接覆盖
  • 因此可以只写需要的字段，例如 asset_types.domain.priority

列表覆盖陷阱

plugins.disabled 这类列表字段是整体替换而非追加。如果你在配置里写了 plugins.disabled: [a]，但内置默认值还有 b，那么 b 将丢失合并。合并顺序：内置默认 → 用户配置，用户配置完全覆盖同名列表。

配置结构总览¶

strategy: priority_based        # 繁殖策略
asset_scope: {...}              # 扫描范围
concurrency: {...}              # 并发
max_depth: 4                    # 最大深度
resource_limits: {...}          # 资产上限
asset_types: {...}              # 各类型开关与工具
output: {...}                   # 输出
external_tools: {...}           # 外部工具
language: {...}                 # 语言
exclusions: {...}               # 排除规则
http: {...}                     # HTTP 行为
plugins: {...}                  # 插件（模板才有）
checkpoint: {...}               # 断点（模板才有）
monitoring: {...}               # 监控（模板才有）

全局¶

strategy: priority_based   # priority_based | depth_first | breadth_first | time_based

max_depth: 4               # 最大发现深度（可被 --depth 覆盖）

asset_scope — 资产扫描范围¶

asset_scope:
  restrict_to_seed_domains: true     # 限制仅在种子域名范围内
  restrict_to_seed_ip_ranges: false  # 限制仅在种子 IP 段范围内
  include_subdomains: true           # 包含子域名
  include_ip_ranges: true            # 包含 IP 段

concurrency — 并发¶

concurrency:
  max_tasks: 20       # 全局最大并发任务数（线程池大小）
  tools:              # 各工具独立并发
    subfinder: 2
    naabu: 2
    jsfinder: 2

resource_limits — 资产数量上限¶

超出上限的资产会被 excluded：

resource_limits:
  max_domains: 2000
  max_ips: 2000
  max_urls: 5000
  max_ports: 5000
  max_js: 5000

asset_types — 资产类型与工具开关¶

每个类型可配置：是否启用、深度上限、优先级、工具开关。

asset_types:
  domain:
    enabled: true
    depth_limit: 3        # 该类型挖掘深度上限
    priority: 10          # 数值越高越优先处理
    tools:
      subfinder: true     # 子域名发现
      free_subfinder: false  # 免费被动源聚合
      crtsh: true         # CRT.sh 证书透明日志
      dns_brute: true     # 内置 DNS 暴力枚举
      dnsx: true          # DNS 解析验证
  ip:
    enabled: true
    depth_limit: 4
    priority: 8
    tools:
      naabu: true             # 端口扫描
      reverse_dns: true       # 反向 DNS
      port_range: '1-1024,3306,3389,5432,5900,6379,7001,8000-8500,8888,9000-9100,9200,27017,11211'  # （模板有，本文件无）
  url:
    enabled: true
    depth_limit: 5
    priority: 10
    tools:
      jsfinder: true      # JS 提取
      link_extract: true  # 超链接提取
      fingerprint: true   # 站点指纹
    title_extraction:     # 标题提取
      enabled: true
      max_length: 50      # 上限长度，超长截断
      show_in_report: true
      show_in_csv: true
  port:
    enabled: true
    depth_limit: 5
    priority: 7
    tools:
      service_identify: true  # 服务识别
  js:
    enabled: true
    depth_limit: 4
    priority: 6
    tools:
      jsfinder: true

默认优先级

若不配置 priority，内置默认值为 domain=5、url=4、ip=3、port=2、js=1。

output — 输出¶

output:
  dir: output                    # 输出根目录（可被 -o 覆盖）
  graph_format: json             # 保留项，实际由 formats 控制
  asset_report: json             # 保留项
  keep_eliminated_assets: true   # 在报告中保留被排除的资产
  formats:
    json: true      # JSON 资产图
    csv: true       # 两个 CSV（资产+关系）
    graphml: true   # GraphML 拓扑
    html: true      # HTML 报告
  auto_open: true   # 扫描完成自动打开报告
  output_prefix: zsans   # 输出文件前缀（模板有）

external_tools — 外部工具¶

external_tools:
  paths:                 # 自定义路径，不填则按工具探测顺序查找
    subfinder: null      # 如 /usr/bin/subfinder
    naabu: null          # 如 D:\naabu\naabu.exe
    ehole: null          # EHole 指纹工具
    whatweb: null        # WhatWeb 指纹工具
  fingerprint:              # 指纹识别
    enabled: true           # 使用本地多架构 EHole
    engine: auto            # auto | ehole | whatweb | both | none
  jsfinder_timeout: 30      # JSfinder 超时（秒，模板有）

工具探测顺序（详见工具集成）：

  1. 配置 external_tools.paths.<name>
  2. 内置目录 tools/<name>/... / assets/<name>
  3. 系统 PATH

language — 国际化¶

language:
  default_language: en      # zh_CN 或 en
  supported_languages:
    - zh_CN
    - en
  locale_dir: i18n          # 语言文件目录

详见国际化。

exclusions — 排除规则¶

命中排除规则的资产会标记 excluded 并触发 on_asset_excluded。

exclusions:
  domains:        # 排除域名（精确或其后缀 .<domain>）
    - example.com
    - test.local
  ips:            # 排除 IP（精确）
    - 127.0.0.1
    - 0.0.0.0
  urls:           # URL 含关键词即排除
    - login
    - logout
  ports: []       # 排除端口
  patterns:       # 正则排除（常见静态资源后缀）
    - \.(css|jpg|jpeg|png|gif|svg|woff|woff2|ttf|eot)$

http — HTTP 行为¶

http:
  timeout: 10              # 单次请求超时（秒）
  retries: 3               # 重试次数（重试 429/5xx）
  user_agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.124 Safari/537.36
  verify_ssl: false        # 校验 SSL 证书（自签名站点需 false）
  proxy: null              # HTTP 代理
  follow_redirects: true   # 跟随重定向
  redirect_as_new_asset: true  # 重定向目标作为新资产收录
  max_redirects: 5         # 单条链接最大重定向次数

plugins — 插件（模板提供）¶

plugins:
  dir: null       # 插件目录，null 时使用项目根目录的 plugins/
  disabled: []    # 需要禁用的插件名列表

checkpoint — 断点续扫（模板提供）¶

checkpoint:
  enabled: true   # 启用断点保存
  interval: 50    # 每处理 50 个资产保存一次
  file: null      # 断点文件路径，null 用 <output_dir>/checkpoint.json

monitoring — 监控（模板提供）¶

monitoring:
  enabled: false   # 是否启用（实际生效由 --watch 决定）
  interval: 3600   # 轮询间隔（秒）
  webhook_url: null # 变更告警 Webhook（POST JSON）

monitoring.enabled 实际未参与判断

进入监控模式由 CLI 参数 --watch 决定；代码只读取 interval 与 webhook_url。

顶层的优先级链¶

配置来源 优先级
CLI 参数（--depth、-o） 最高（覆盖配置）
breeding-config.yaml 用户配置 中
内置 DEFAULT_CONFIG 最低（兜底）
